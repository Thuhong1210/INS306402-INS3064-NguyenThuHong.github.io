# Campus Service Request - Week 10 MVC Skeleton

This is an optional PHP skeleton for the Week 10 homework.

## How to run with XAMPP

1. Copy the folder `campus_service_request_week10_full` to `C:\xampp\htdocs`.
2. Start Apache in XAMPP.
3. Open this URL in the browser:

```text
http://localhost/campus_service_request_week10_full/public/index.php
```

## Features included

- View request list
- Submit a request
- View request details
- Update request status
- Simple MVC folder structure
- Session-based storage, no database required
